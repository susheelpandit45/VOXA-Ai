# VOXA AI

AI-powered multilingual communication keyboard.

## Vision

Type or speak in your comfortable language and generate the desired language directly from the keyboard.

## Core Features

- Multilingual input
- AI translation
- AI rewriting
- Professional mode
- Casual mode
- Voice input
- Direct text insertion
- Privacy-focused design

## Initial Version

Marathi → English

## Future Languages

Hindi, Tamil, Telugu, Bengali, Gujarati, Kannada and Malayalam.

## Platform

Android

## Technology

- Kotlin
- Android InputMethodService
- AI API
- Speech Recognition
